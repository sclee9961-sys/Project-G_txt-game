# 미궁

React + Vite로 만든 브라우저 텍스트 게임입니다.
지하 10층의 어둠 속에서 깨어나, 손전등 하나로 열 개의 층을 올라 지상 출구를 찾아 탈출합니다.
화면은 A Dark Room 계열의 미니멀 인크리멘털처럼 어두운 배경에 글과 테두리만으로 구성했습니다.

## 실행

```powershell
npm install        # 처음 한 번
npm run dev        # 개발 서버 (http://localhost:5173)
```

PowerShell에서 실행 정책 오류가 나면 `npm.cmd install`, `npm.cmd run dev`로 실행하거나
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`를 한 번 실행하세요.

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 실행 (코드를 고치면 화면이 바로 갱신) |
| `npm test` | 테스트 실행 (게임 규칙 + 화면 흐름) |
| `npm run build` | 배포용 빌드 (`dist/` 폴더 생성) |
| `npm run lint` | 코드 검사 |

## 게임 방법

- **시작**: 타이틀에서 "눈을 뜬다"를 누르면 칠흑 같은 어둠과 하수구 분위기의 지문(눅눅한 공기, 고인 물 냄새,
  물 흐르는 소리)이 먼저 나오고 "주변을 둘러본다"만 고를 수 있습니다. 그걸 골라야 깨어난 순간의 지문
  (손전등과 쪽지 하나가 있었다는 것, "이 곳을 탈출하라"는 쪽지)이 나오고 탐색이 시작됩니다.
- **전진**: 한 걸음마다 빛이 1 줄고 사건이 일어납니다. 아무 일도 없거나, 물건을 줍거나,
  적을 만나거나, 함정에 걸리거나, 길을 잃어 한 칸 되돌아갑니다.
- **돌아간다**: 입구 쪽으로 한 걸음 스스로 물러납니다. 이미 지나온 자리라 빛이 들지 않고 사건도 일어나지 않지만,
  그 자리에 곁길·갈림길·잠긴 문이 있으면 다시 안내해 줍니다. 입구까지 물러나면 이 선택지는 사라집니다.
- **빛**: 손전등이 꺼지면 적과 함정, 길 잃음이 훨씬 자주 일어납니다. 배터리로 충전하세요.
  최대 체력·최대 빛은 처음엔 낮게 시작하고, 대신 실험실의 혈청과 손전등 개조로 늘려 갈 수 있습니다(아래 참고).
- **쉰다**: 체력을 조금 회복합니다. 층마다 횟수가 정해져 있고, 쉬다가 습격당할 수 있습니다.
- **지도**: 지나온 칸마다 둘레 3x3(상하좌우 1칸)씩 계속 기억해 그립니다. `.`는 갈 수 있는 길, `@`는 현재 위치,
  `^`는 출구, `#`는 벽(또는 아직 안 연 잠긴 문)입니다. 지도 전체 틀(캔버스)의 크기는 층이 위로 올라갈수록(3개 층마다
  한 단계씩) 커지지만, 화면에는 그중 플레이어를 따라다니는 고정 크기(9x9) 창만 보입니다 — 멀리 이동해 그 창을 벗어나면
  지나온 자리도 화면에서는 다시 안 보이고(카메라가 따라가며 잘라 낼 뿐, 기억 자체는 그대로입니다), 반대로 가면 다시 보입니다.
  상태·소지품 상자와 같은 테두리를 쓰고, 방향키(↑↓←→)로 지도의 방향에 맞게 나아가거나 물러날 수 있고, 갈림길 문 앞에서는
  그 방향의 방향키로 곧장 들어갈 수 있습니다.
- **계단을 오른다**: 이동 칸을 끝까지 채우면 계단이 나타납니다. 지하 10층에서 시작해 지하 1층까지 총 10개 층입니다.
- **이정표**: 각 층에 막 들어서면 몇 층인지, 어디인지 모릅니다. 위쪽 제목과 지도에도 `???`만 보입니다.
  두 번째 걸음쯤에서 반드시 이정표(팻말·표찰 등)를 발견해야 "지하 N층 · 장소"가 드러납니다. 한 번 알면 그 층에서는
  계속 알고 있고, 다음 층으로 오르면 다시 모르는 상태로 시작합니다.
- **곁길과 방**: 통로 중간의 곁길을 지나면 문이 보이고 지도에도 그려집니다. 방은 한 번만 들어갈 수 있고(문을 지나는 순간
  소진됩니다) 빛이 1 듭니다. 안 들어가도 클리어할 수 있지만, 방을 이용하지 않으면 매우 어렵습니다.

  | 방 | 지도 글자 | 효과 |
  | --- | --- | --- |
  | 휴게실 | R | 방 화면에서 "쉰다"를 고르면 체력을 모두 회복하고 이 층의 휴식 횟수를 채웁니다 |
  | 보급실 | S | 방 화면에 있는 아이템 목록에서 하나씩 골라 챙깁니다. 다 안 챙기고 나가도 됩니다 |
  | 의무실 | M | 방 화면에서 "치료받는다"를 고르면 최대 체력이 영구히 +10 늘고 체력이 모두 회복됩니다 |
  | 자료실 | A | 방 화면에서 "쪽지를 읽는다"를 고르면 이곳의 정체를 알려주는 쪽지가 나옵니다. 읽은 쪽지는 수첩에 적힙니다 |
  | 실험실 | E | 문을 지나자마자 강한 장비와 **강화 혈청**(최대 체력 +15, 소지품에서 직접 써야 적용됩니다)을 함께 얻고, 곧바로 경비가 깨어나 싸우게 됩니다 (기계 경비·실험체 중 하나가 매번 무작위로 나옵니다) |
  | 단말실 | T | 접속 화면으로 이어집니다. 계정과 비밀번호를 맞게 입력해야 소진되고 이 미궁의 기록을 열람할 수 있습니다 |
  | 막다른 길 | X | 문을 지나자마자 끝입니다. 아무것도 없습니다 |
  | 매복 | K | 문을 지나자마자 보상 없이 적이 바로 나타납니다 |

  휴게실·보급실·의무실·자료실·단말실은 문을 지나면 곧장 효과가 나오지 않고, 그 방 전용 화면으로 넘어가 안에서
  직접 행동을 골라야 효과가 적용됩니다. (실험실·막다른 길·매복은 예전처럼 문을 지나자마자 곧장 결과가 나옵니다)
  방 화면에서도 지도는 계속 보이며, 위쪽 층 이름 옆에 지금 있는 방 이름이 함께 표시되고 지도의 `@`는 그 방의
  글자 자리로 옮겨 겹쳐 보입니다.

  휴게실·보급실·의무실·자료실에는 정해진 행동(쉰다/치료받는다/쪽지를 읽는다/아이템 챙기기)과 별개로, 방을
  나서기 전까지 하나씩 더 골라 볼 수 있는 **조사 지점**이 있을 수 있습니다. "선반을 살펴본다"처럼 방마다
  다른 선택지로 나타나고, 고르면 문장만 나오거나(꽝), 아이템을 하나 더 챙기거나, 위험한 것과 마주쳐 전투로
  이어지기도 합니다(이기면 방 밖이 아니라 그 방 안으로 돌아옵니다). 한 번 조사한 지점은 다시 나오지 않습니다.

  아직 안 가 본 방은 대문자, 다녀온 방은 소문자로 표시됩니다.
- **갈림길**: 같은 지점에 방이 두 개 있으면("문패: 관리 초소" 대신 "길이 두 갈래로 갈라진다"로 안내됩니다) 갈림길입니다.
  왼쪽·오른쪽 중 어느 쪽부터 들어가도 되고, 한쪽이 막다른 길이거나 매복이어도 되돌아가서 다른 쪽을 갈 수 있습니다.
  지도에는 길이 갈라지는 것만 보이고, 안 가 본 쪽에 무엇이 있는지는 막다른 길이라도 `?`로 가려집니다.
  가 보면 그제야 실제 글자로 바뀝니다. (지하 10층, 지하 7층에 시범으로 넣었습니다)
- **잠긴 문**: 곁길의 방과 달리 통로 자체를 막습니다. 문에 다다르면 "전진" 대신 "잠긴 문을 살펴본다"가 나오고,
  올바른 비밀번호를 넣기 전까지는 그 너머로 갈 수 없습니다. 틀리면 체력이 조금 깎이지만 몇 번이든 다시 시도할 수 있고,
  물러나서 다른 곁길을 둘러보다 다시 올 수도 있습니다. 비밀번호는 보통 문에 닿기 전에 지나온 같은 층의 자료실 쪽지에 있습니다.
  지도에는 아직 안 연 문이 `#`로 그려집니다. (지하 3층에 시범으로 넣었습니다)
- **수첩**: 쪽지를 하나라도 읽으면 선택지에 나타납니다. 읽은 쪽지를 층과 방별로 다시 볼 수 있고, 단말 접속 화면에서도 열 수 있습니다.
- **단말 접속**: 단말실의 계정과 비밀번호는 한 곳에 통째로 적혀 있지 않습니다. 여러 층의 자료실 쪽지에 조각으로 흩어져 있어서
  수첩을 보며 맞춰야 합니다. 계정은 그 순간의 **피험자 번호**이고, 번호는 쓰러질 때마다 1씩 늘어납니다.
  (수첩 속 쪽지의 번호 조각도 함께 바뀝니다. 죽은 뒤에는 수첩을 다시 확인해야 합니다.) 틀려도 횟수 제한 없이 다시 시도할 수 있고, 계정만 맞았는지 알려줍니다. 대소문자, 하이픈, 공백은 무시합니다.
- **장비와 장착**: 통로에서 반드시 얻는 장비(쇠 파이프, 두꺼운 작업복, 지렛대, 방폭 조끼)와, 실험실에서만 얻는 더 강한 장비
  (소방 도끼, 방호복, 전기 충격봉)가 있습니다. 무기나 방어구를 얻으면 곧장 적용되지 않고, 장착할지 물어보는 화면이 먼저 뜹니다.
  장착하지 않아도 소지품에는 남아 있어서, 소지품 화면에서 언제든 꺼내 장착(갈아 끼우기)할 수 있습니다. 공격·방어에는 장착한
  장비만 반영됩니다.
- **소지품 용량과 가죽**: 소모품·재료·혈청은 가방에 담을 수 있는 양이 정해져 있습니다(처음엔 10개). 장비(무기·방어구)는 하나만 쓰이므로
  용량을 차지하지 않습니다. 가득 차면 더 얻지 못하고("소지품이 가득 차 챙기지 못했다") 그 자리에 남겨 두게 됩니다.
  적을 쓰러뜨리면 장비·소모품과 별개로 **가죽**을 얻을 때가 있습니다. 소지품 화면에서 가죽 5개를 조합하면 가방을 키워
  용량이 10개 늘어나고, 몇 번이든 다시 키울 수 있습니다.
- **최대 체력·최대 빛 늘리기**: 실험실에서 얻는 **강화 혈청**을 소지품에서 쓰면 최대 체력이 영구히 +15 늘고 체력이 모두 찹니다.
  최대 빛은 **기계부품**(부품 창고에 있고, '기계' 계열 적을 쓰러뜨리면 뜯어낼 때도 있습니다)을 소지품 화면에서 3개 모아
  손전등을 개조하면 +15 늘어나고, 몇 번이든 다시 개조할 수 있습니다. (의무실에서 늘어나는 최대 체력과는 별개의 방법입니다)
- **문지기**: 지하 1층 끝의 출구 문은 문지기가 지킵니다. 도망칠 수 없습니다.
- 쓰러지면 그 층의 입구에서 절반의 체력과 절반의 빛으로 깨어납니다. (그 층에서 나아간 것은 사라집니다)
- 탐색 중에는 자동 저장되고, 탈출하면 이어하기 기록이 지워집니다.
- 숫자 키(1~9)로도 선택할 수 있습니다.

## 폴더 구조

```
src/
├─ game/          게임 규칙 (React와 무관한 순수 함수 — 테스트하기 쉬움)
│  ├─ config.js     ← 밸런스 숫자(초기 능력치, 사건 확률, 휴식 횟수 등)
│  ├─ data.js       ← 아이템 / 적 / 방 종류 / 층 목록과 문장
│  ├─ character.js  플레이어·적 생성, 피해 계산, 저장 데이터 검증
│  ├─ items.js      아이템 사용, 소지품 목록
│  ├─ explore.js    한 걸음 나아가기 / 쉬기 / 계단 오르기
│  ├─ battle.js     전투 한 턴 처리
│  ├─ rooms.js      곁길의 방 (들어갈 수 있는 방, 방 종류별 효과)
│  ├─ map.js        지나온 칸마다 3x3씩 쌓이는 시야로 지도(., #, @, ^ 글자) 그리기 + 그중 플레이어를 따라다니는 고정 창만 자르기
│  ├─ save.js       localStorage 저장 / 불러오기
│  └─ util.js       난수, 가중치 뽑기, 조사(이/가, 을/를) 처리
├─ hooks/
│  └─ useGame.js    화면 전환과 로그 기록을 관리하는 훅 (탐색 화면의 방향키 ↔ 선택지 매칭 포함)
├─ components/    화면 조각 (기록, 선택지 버튼(숫자·방향키), 상태·적·지도·소지품 상자)
├─ App.jsx
└─ index.css      ← 색과 글꼴은 맨 위 :root 변수에서 바꿉니다
```

**규칙은 `src/game/`, 화면은 `components/`, 둘을 잇는 것은 `useGame.js`** 로 나뉘어 있습니다.

## 내용 추가하기

- **층 추가/수정**: [src/game/data.js](src/game/data.js)의 `floors`. 순서대로 위층이 되며,
  `length`(계단을 찾기까지의 걸음 수), 지도에 그려질 통로 모양(`path`, `RDLU`로 쓰고 글자 수는 `length`와 같게),
  분위기 문장(`ambient`), 나오는 적, 주울 수 있는 것, 반드시 얻는 장비(`finds`), 곁길의 방(`rooms`)을 정합니다.
  방은 `at`(몇 번째 칸에서 갈라지는지), `dir`(방향), `kind`(종류)와 들어갔을 때의 문장(`text`)을 적습니다.
  `sign: { at, text }`는 그 칸에서 반드시 발견하는 이정표로, `text`의 마지막 줄은 관례상 `「지하 N층 · 장소」` 형태로 적습니다.
  휴게실/보급실/의무실/자료실에는 `searches: [{ id, label, text, item?, count?, enemy? }]`로 조사 지점을 추가할 수 있습니다.
  `item`이 있으면 그것을 챙기고(기본 1개), `enemy`가 있으면 위험한 것과 마주쳐 전투로 이어지며, 둘 다 없으면 문장만 나옵니다.
- **잠긴 문 추가/수정**: 같은 층 객체에 `gate: { at, password, text, openText }`를 추가합니다. `at`은 문이 걸려 있는 지점(그
  하나 앞 칸에 다다르면 문이 보입니다), `password`는 여는 값, `text`는 문 앞에서 매번 보여줄 문장, `openText`는 연 순간의
  문장입니다. 비밀번호 단서는 보통 그 앞쪽의 `archive` 방 쪽지에 적어 둡니다. 층 하나에 문은 하나만 지원합니다.
- **단말 계정/비밀번호 바꾸기**: 단말실(`kind: 'terminal'`)의 `login`을 고치고, 그 값의 조각을 자료실 쪽지에 나눠 적습니다.
  쪽지와 계정에는 자리표시자 `{번호}`(피험자 번호 네 자리), `{번호앞}`, `{번호뒤}`(앞·뒤 두 자리), `{투입}`(투입 횟수)을 쓸 수 있고
  플레이어의 현재 값으로 바뀝니다. 시작 값은 [src/game/config.js](src/game/config.js)의 `subjectStart`, `insertionStart`입니다.
  완성된 값이 한 쪽지에 통째로 있으면 테스트가 실패합니다. (조각이 하나라도 빠져도 실패합니다)
- **방 종류 추가**: `roomKinds`에 이름과 지도 글자를 추가하고, [src/game/rooms.js](src/game/rooms.js)의 `effects`에 효과를 추가합니다.
- **적 추가**: 같은 파일의 `enemies`에 추가하고, 나오게 할 층의 `enemies` 목록에 id를 적습니다.
- **아이템 추가**: 같은 파일의 `items`에 추가합니다. `type`은 `heal`, `light`, `vitality`, `weapon`, `armor`, `material`을 지원합니다.
  `material`(가죽·기계부품 같은 조합 재료)과 `vitality`(혈청처럼 최대 체력을 영구히 늘리는 아이템)는 `heal`, `light`와 함께
  소지품 용량을 차지합니다. 새 종류의 소모품은 [src/game/items.js](src/game/items.js)의 `useItem`에 동작을 추가합니다.
- **밸런스 조정**: [src/game/config.js](src/game/config.js)의 숫자만 수정합니다.

## COMPUTER 방 (연출 시험, 개발 전용)

미궁 끝에서 COMPUTER(시설 관리 AI)와 마주하는 마지막 장면입니다. 자유 대화 + LLM 응답으로 시험해봤으나
결말을 의도대로 끌고 가게 지시하기 어려워서, 미리 써둔 대화 나무([src/game/computerDialogue.js](src/game/computerDialogue.js))를
선택지로 따라가는 방식으로 바꿨습니다. 어두운 방 → 조명 켜짐(깜빡임) → 모니터로 다가감 → 대화 → ESCAPE/DESTROY/SUICIDE
세 결말 중 하나로 갈라지는 흐름이 [src/components/ComputerScene.jsx](src/components/ComputerScene.jsx) 하나에 모여 있습니다.

아직 게임 결말·별관 확장과는 안 이어져 있고, 개발 서버(`npm run dev`)의 화면 상단 "COMPUTER 방 (장면 시험)" 버튼으로만 열립니다.
배포 빌드(`npm run build`)에는 이 버튼이 포함되지 않습니다.
